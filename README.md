# 麦门减脂营养师（MC Nutrition Expert）

> 麦当劳程序员节创意开发大赛参赛作品 · 基于麦当劳 MCP 官方餐品数据能力的减脂配餐 Web 应用

减脂期也想吃麦当劳？填写身高体重、活动量与忌口，应用自动过滤过敏原餐品，生成 **3 套总热量严格控制在目标 ±5% 的早+午+晚麦当劳套餐**，横向对比、一键替换，全程 Markdown 表格输出。

> ⚠️ 本项目为参赛者独立开发的参赛作品，非麦当劳官方产品；输出仅供参考，不构成医疗或营养专业建议；餐品信息、价格及供应状态以麦当劳官方渠道实时结果为准。详见 [CONTEST_DECLARATION.md](./CONTEST_DECLARATION.md)。

## ✨ 功能特性

1. **用户信息收集**：性别、身高、体重、日常活动量、每日热量上限、过敏原（10 类多选）与自定义忌口；必填项缺失逐项中文引导补齐，并实时展示 BMR/TDEE 参考值（Mifflin-St Jeor 公式）辅助设定热量目标。
2. **过敏原/忌口自动过滤**：配餐前剔除命中用户过敏原或忌口关键词的餐品；推断类过敏原数据全程标注"非官方声明"。
3. **三套控卡方案**：控卡优先（热量近下限+低钠）/ 性价比优先（每 100kcal 蛋白质最高）/ 饱腹感优先（蛋白+脂肪+克重最高），每套总热量严格落在目标 ±5%，早餐仅从早餐餐段选取。
4. **Markdown 输出**：餐品清单表格（餐段/名称/价格/热量/蛋白/碳水/脂肪/钠）+ 分割线 + 整套总价/总热量 + 三大营养素汇总与供能比，前端整齐渲染。
5. **横向对比板块**：3 套方案营养与价格对比表，标注各自适用场景。
6. **额外指令**：按名称查询任意单品完整营养；"不喜欢→自动替换"为同分类、同餐段、热量 ±10% 且整套仍达标的其他单品，支持还原。

## 🛠 技术栈

Vue 3.5 · Vite 6 · Element Plus 2.9 · marked 15（纯前端 SPA，无后端依赖）

## 📦 安装与运行

```bash
# 环境要求：Node.js >= 18
npm install
npm run dev      # 本地开发，默认 http://localhost:5173
npm run build    # 生产构建，产物在 dist/
```

## 📖 使用示例

1. 打开页面，填写：女 / 165cm / 60kg / 久坐 / 每日热量上限 1400 kcal / 过敏原勾选"牛奶"；
2. 点击"生成减脂方案"，得到 3 套方案卡片（实测总热量 1330 / 1403 / 1469 kcal，均在 ±5% 内，且不含牛奶过敏原餐品）；
3. 查看底部横向对比表，选定心仪方案；
4. 对方案中某单品点"不喜欢→自动替换"，系统换成同类型、热量差 ≤10% 的在售单品并实时重算汇总；
5. 在"单品营养查询"中搜索"麦香鱼"，查看其完整营养数据。

## 🎯 目标用户

- 减脂/控卡期仍想在麦当劳就餐的人群；
- 对特定过敏原或忌口有过滤需求的麦当劳顾客；
- 关注高蛋白、低钠饮食搭配的健身人群；
- 希望快速了解麦当劳单品营养价值的普通消费者。

## 📁 项目结构

```
├── src/
│   ├── data/mcdonalds-menu.json      # 麦当劳中国官网真实餐品数据快照（91 个单品，MCP 返回格式）
│   ├── services/mcpClient.js         # 统一数据入口，可无缝替换为麦当劳 MCP 在线调用
│   ├── utils/
│   │   ├── nutrition.js              # BMR/TDEE 计算
│   │   ├── planGenerator.js          # 三策略套餐生成（±5% 热量约束）
│   │   ├── substitute.js             # 单品替换与还原
│   │   └── markdownOutput.js         # Markdown 表格输出
│   └── components/                   # 表单 / 方案卡片 / 对比面板 / 单品查询
├── CONTEST_DECLARATION.md            # 参赛声明（官方原文）
├── MCP_INTEGRATION.md                # 麦当劳 MCP Server/Tool/调用流程说明
└── .trae/specs/                      # Spec 驱动开发的过程文档（spec/tasks/checklist）
```

## 🔌 MCP 集成与数据口径

本项目数据层严格对齐麦当劳 MCP `list-nutrition-foods` 等工具的返回结构，当前演示版运行于官网数据快照模式（过敏原为推断数据、单品价格官网未公开）。接入方式、Tool 清单与切换方案详见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。
